### 赋值、浅拷贝与深拷贝
1. **赋值（=）：完全共享**
`a = b`，无论 a 和 b 是什么类型，都只是把标签贴到同一个对象上。 
    - 如果 b 是不可变对象：修改 a 会新建对象，b 不受影响
    - 如果 b 是可变对象，修改 a，b 会跟着一起变！

2. **浅拷贝：外层独立，内层共享**
使用 `copy.copy()`、`list()`、`dict()`、切片 `[:]` 。
    - 创建一个新的外层容器（新 id）
    - 新容器内的对象是原来容器内的对象的标签（引用）


3. **深拷贝（Deep Copy）：彻底克隆**
使用 `copy.deepcopy()`
    - 递归复制所有层级的对象，直到最底层不可变对象
    - 两份数据完全独立，修改任何一个，另一个绝对不受影响

```python
import copy
lst1 = [1, [2, 3]]
lst2 = copy.copy(lst1)      # 浅拷贝
lst3 = copy.deepcopy(lst1)  # 深拷贝

lst2[1].append(4) 
print(lst1) # [1, [2, 3, 4]] 原列表跟着变了！
print(lst3) # [1, [2, 3]]    深拷贝不受影响
```

### 嵌套可变对象的乘法

在 Python 中，乘法（*）操作对于序列（如 list、tuple、str）来说，**默认执行的是浅拷贝（Shallow Copy）**。

```python
list1 = [[]] * 3 # [[], [], []] 
# 修改操作
list1[1].append(1) # [[1], [1], [1]] 
# 赋值操作
list1[2] = [1, 2] # [[1], [1], [1, 2]]
```

正确写法是使用**列表推导式**
```python
list1 = [[] for _ in range(3)]
list1[1].append(1) # [[], [1], []] 互不影响！
```
