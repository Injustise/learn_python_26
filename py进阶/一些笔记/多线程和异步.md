### 异步处理：

asyncio 的事件循环（Event Loop）本质上就是一个**任务调度队列**。

- 内部维护着就绪队列和等待队列。
- 当一个协程遇到 await 时，它就被扔进等待队列，而 CPU 则去就绪队列中找下一个任务跑

### 总结：
1. **异步（Asyncio）**：
    - 单线程 + 事件循环队列 + 协作式调度（await 主动让出）。
    - 无锁、内存极小、高并发 I/O 的神器。

2. **多线程（Threading）**：
   - 多线程 + OS 抢占式调度[^1] + 锁机制。
   - 简单粗暴、兼容老代码、适合百级别并发。

3. **多进程（Multiprocessing）**：
   - 多核心 + 独立内存 + 真并行。
   - 适合 CPU 密集型计算。

[^1]: 操作系统（OS）有种时间片轮转机制。当一个线程【运行时间超出对应时间片，主动阻塞，被更高优先级抢占】时，OS 会强行暂停（抢占式调度），把 CPU 给另一个线程。
